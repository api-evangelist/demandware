# Demandware (Salesforce B2C Commerce Cloud)

> Demandware is the cloud commerce platform now sold by Salesforce as Salesforce B2C Commerce Cloud (acquired 2016). Its developer surface is two REST API families: the modern B2C Commerce API (SCAPI) and the deprecated Open Commerce API (OCAPI), with first-party SDKs, CLIs, an MCP server, and OAuth2 (SLAS / Account Manager) authentication.

## APIs

- [B2C Commerce API (SCAPI)](https://developer.salesforce.com/docs/commerce/commerce-api/overview): Shopper APIs, Admin APIs, and Shopper Login and API Access Service (SLAS). OpenAPI, OAuth2/JWT.
- [Open Commerce API (OCAPI, deprecated)](https://developer.salesforce.com/docs/commerce/b2c-commerce/references/b2c-commerce-ocapi): Shop, Data, and Meta APIs. Swagger 2.0, OAuth2 via Account Manager.
